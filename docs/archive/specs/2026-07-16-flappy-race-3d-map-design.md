# Flappy Race — 3D 맵 씬 설계

- **작성일**: 2026-07-16
- **산출물**: 유니티 씬 하나 (아트/환경 중심). 게임 로직은 이후 별도 작업.
- **파이프라인**: 스케치팹 → 블렌더 후처리 → 유니티 (기존 LOP 에셋 파이프라인 재사용)

## 1. 개요 / 컨셉

- **장르**: 3D(2.5D 공유 평면) 횡스크롤 원버튼 점프, 최대 4~8인 멀티 레이스
- **톤**: 오리지널 플래피 버드 (파란 하늘, 초록 파이프, 심플 카툰)
- **코스 구조**: 고정 길이 레이스 코스 (시작 → 결승선). 엔드리스/절차생성 아님.
- **플레이어 배치**: 2.5D 공유 평면 — 모두 같은 Z 평면에서 비행, 서로 몸싸움/추월 가능.
- **좌표 규약**:
  - X축 = 진행 방향(횡스크롤)
  - Y축 = 상하(점프)
  - Z = 얇은 깊이, 모든 플레이어 동일 평면
  - 카메라는 -Z에서 측면(side view)으로 바라봄

## 2. 에셋 목록 (스케치팹 쇼핑 리스트)

CC 라이선스 무료 에셋 위주로 받아 블렌더에서 톤 통일. 단순한 건 블렌더 직접 모델링.

| 요소 | 받을 것 | 비고 |
|---|---|---|
| 파이프 장애물 | 초록 파이프/튜브 (없으면 블렌더 직접 모델링 — 실린더 2개라 간단) | **필수**, 위/아래 쌍 프리팹화 |
| 지면/바닥 | 잔디+흙 띠 (플랫폼/그라운드) | 반복 타일 |
| 배경 | 하늘 스카이박스/구름 카드, 도시 실루엣 | 원경 |
| 시작/결승선 | 게이트/아치 구조물 | 2개 |
| placeholder 새 | 카툰 새 (스케치팹) | 스케일 확인용 1마리 |
| 장식 | 덤불, 구름 오브젝트, 코인/점수링 | 분위기 |

> 파이프처럼 단순한 형태는 스케치팹에 딱 맞는 게 없으면 블렌더에서 바로 모델링하는 편이
> 더 빠르고 톤 통일도 잘 됨. 실제 build 때 에셋별로 판단.

## 3. 블렌더 후처리

기존 파이프라인 gotcha 그대로 적용 (스케일/피벗, metallic 0, 선형→sRGB, UV 없음):

- 에셋별 스케일·피벗 정규화 (바닥 중심), 트랜스폼 적용
- 머티리얼 톤 통일 — 플래피 카툰 팔레트: 밝은 초록 / 하늘색 / 노랑
- URP Lit 호환 세팅, 필요 시 UV 재전개
- FBX로 export → 유니티 반입

## 4. 유니티 씬 구성

- **씬 이름**: `FlappyRace.unity` (경로는 LOP 클라이언트 프로젝트 내 — build 때 확정)
- **계층 구조**:
  - `---Environment---`: Ground(반복), Skybox/구름, 도시 실루엣, 장식(덤불)
  - `---Course---`: StartGate → PipePair ×N (X축 일정 간격 배치) → FinishArch
  - `---Players---`: PlayerSpawn 포인트 ×8, placeholder 새 1마리
  - `---Lighting---`: Directional Light(맑은 낮), 카툰톤 라이팅
  - `---Camera---`: 측면 카메라(-Z), 참고용
- **코스 스코프**: 파이프 쌍 약 10~15개, 완주 가능한 길이 (레이스 1판 감)
- 파이프 쌍은 프리팹으로 만들어 간격/높이 변주 배치

## 5. 파이프라인 실행 순서

1. 스케치팹 에셋 검색·다운로드 (블렌더 MCP)
2. 블렌더 후처리 → FBX export
3. 유니티 씬 생성 + 계층 구성 (Unity MCP)
4. 에셋 배치 → 파이프 프리팹화 → 코스 레이아웃
5. 라이팅/카메라 세팅 → 뷰포트 스크린샷으로 확인

## 범위 밖 (이번 세션 제외)

- 게임 로직 (탭 점프, 파이프 충돌, 점수, 네트워크 동기화)
- 실제 멀티플레이어 서버 연동
- 최종 아트 폴리싱 / 사운드
