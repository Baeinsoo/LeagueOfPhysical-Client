# 0013. 플래피 미니게임의 공개 이름은 "Flappy Race"로 하고, 스토어 메타데이터에는 Flappy를 쓰지 않는다

- 상태: Accepted
- 날짜: 2026-08-14
- 관련: [플래피 멀티 컨셉](../superpowers/specs/2026-08-05-flappy-multiplayer-concept-design.md) · 마스터데이터 `GameMode` 표 (`code: FlappyRace`, 이름 "플래피 레이스")

## 맥락

LOP 안의 플래피 미니게임(새를 날갯짓으로 띄워 코스를 통과하는 게임)에 밖으로 내보일 이름이 필요했다. 이름은 두 곳에 쓰인다. 게임 안의 모드 이름, 그리고 앱 스토어에 올릴 때의 메타데이터(앱 이름·부제·키워드·스크린샷·소개문)다.

고려한 것은 세 가지다.

- 이 게임의 목표는 **1등을 가리는 것(순위)** 이다. 뒤에서 쫓아오는 추격자는 긴장을 주려고 얹은 장치일 뿐 목표가 아니다.
- "Flappy Royale"은 2020년에 나온, 같은 컨셉(여러 명이 동시에 하는 플래피)의 실존 게임이다.
- 2014년에 애플이 앱 이름에 "Flappy"가 들어간 앱을 무더기로 반려한 전례가 있다.

## 결정

- 공개 이름은 **Flappy Race**로 한다. 이름은 게임의 목표를 불러야 하므로 Race다.
- 게임 안의 모드 이름, 코드(`FlappyRace`), 팀 안의 호칭에는 Flappy를 그대로 쓴다.
- **앱 이름·부제·스토어 키워드에는 Flappy를 넣지 않는다.** 스크린샷이나 소개문을 쓰다 보면 모드 이름이 새어 들어가므로, 스토어 제출물을 만들 때 한 번 훑는다.

## 결과

- 쉬워지는 것: 코드와 문서의 이름을 바꿀 필요가 없다. 게임 안에서는 익숙한 "플래피"로 바로 알아본다. 스토어 심사에서 이름 때문에 반려될 위험을 줄인다.
- 어려워지는 것: 스토어 메타데이터를 만들 때마다 Flappy가 섞이지 않았는지 사람이 확인해야 한다. 게임 안 이름과 스토어에서 보이는 이름이 다르다.
- 버린 대안:
  - **Flappy Chase / Flappy Brawl**: 추격이나 몸싸움은 목표가 아니라 장치라 게임의 목표를 잘못 알린다.
  - **Flappy Royale**: 이미 있는 게임 이름이다.
  - 처음 결정할 때는 "우리는 새끼리 몸이 부딪히는 것이 Flappy Royale(서로 통과하는 고스트)과의 차이"라는 이유도 있었다. **이 이유는 더 이상 맞지 않는다.** 2026-09-02(대시 설계)와 2026-09-06(충돌 규칙 폐기) 결정으로 새끼리는 아예 부딪히지 않게 됐다. 결정 자체는 위의 다른 이유만으로 유지된다.
- 다시 검토할 조건: 실제 출시 전에 상표 검색을 해야 한다(아직 하지 않았다). 게임의 목표가 순위가 아닌 것으로 바뀌면 이름도 다시 본다.
